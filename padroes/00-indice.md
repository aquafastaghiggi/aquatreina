# Padrões do projeto

Estes arquivos definem **como** o código é escrito. Não são sugestão. Quando o
hábito da IA executora conflitar com eles, eles vencem.

| Arquivo | Assunto |
|---|---|
| `01-codigo-e-nomenclatura.md` | Português no domínio, nomes de tudo |
| `02-laravel.md` | Ações, serviços, policies, requests, eventos |
| `03-livewire-e-filament.md` | Componentes do aluno e painel admin |
| `04-banco-e-migrations.md` | Migrations, a tabela `usuarios`, índices |
| `05-testes.md` | O que testar, como nomear, mínimo por etapa |
| `06-git-e-commits.md` | Branch, commit, PR |
| `07-definition-of-done.md` | Quando uma etapa está realmente pronta |

Leia `01` e `02` antes de qualquer etapa. Os outros, quando a etapa pedir.
